# Contributing

Use GitHub Issues for focused bugs and feature proposals. Describe the operational need, privacy impact, expected behavior, and a minimal reproduction. Do not submit real employee data.

Fork the repository, create a focused branch, add tests, run the complete [quality gate](TESTING.md), and open a pull request. Changes that introduce surveillance, passive activity inference, hidden scoring, or unexplained employee profiling are out of scope.

By participating, you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
